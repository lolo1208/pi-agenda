## 自动验证

```sh
pnpm install --frozen-lockfile
pnpm typecheck
pnpm test
pnpm build
pnpm audit
pnpm audit --prod
```

`pnpm check` 聚合类型、测试和构建。审计失败记录依赖与处置结论，不用生产依赖无报告替代全工具链审查。

`tests/shadow-git-manager.test.ts` 覆盖真实 Git 增删改、CRLF 与项目属性规则、中文空格路径、二进制、空快照、重新打开、排除项、非法提交/路径与元数据联接点。尚不覆盖文件恢复，也不等于 A04 的完整跨平台验收。
