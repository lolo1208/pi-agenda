# 模型配置与 pi 代理接入

Pi Agenda 在 Electron 主进程使用 `@earendil-works/pi-coding-agent@1.1.0` 调用模型。界面通过 IPC 提交任务，pi 的 `AgentSession` 负责流式回复、工具执行、会话历史和上下文压缩。主进程采用 ESM 构建，以加载 SDK。

## 使用步骤

1. 打开「设置 → 模型供应商」，添加供应商连接。Ollama 可以读取本机已安装模型；应用不自动下载或启动模型。
   ChatGPT 订阅选择「在浏览器中授权」，或「复制授权链接」后粘贴到浏览器隐私窗口。浏览器回调页只有在令牌交换和加密保存都完成后才显示成功，应用随后自动加载模型；回调页面无法打开时，可在「浏览器未自动返回？」中粘贴完整的本次回调地址。支持取消授权和退出账号，授权链接 10 分钟后作废。
2. 为每个模型分别设置上下文上限、输出 Token、Temperature、超时和推理开关。连接测试通过同一 pi 引擎运行，但不读取聊天历史或启用项目工具。
3. 打开项目并开始对话。模型支持工具调用时，代理可读取文件、搜索、编辑、写入和执行命令；Windows 使用 PowerShell，其他平台使用 Bash。
4. 聊天中实时显示生成的正文和工具执行状态。停止按钮中断模型请求及当前工具；窗口关闭或页面离开也会停止任务。
5. 需要撤销文件改动时，打开快照侧栏，查看差异并选择「回滚最近改动」。

## 供应商与参数

| 供应商 | 接口 | 参数适配 |
| --- | --- | --- |
| ChatGPT 订阅 | pi 原生 `openai-codex-responses`，浏览器 OAuth | 自动续期；固定 ChatGPT 地址；Temperature 与实际输出长度由服务决定，回复预留 Token 用于本地预算 |
| OpenAI | Chat Completions；包含非 PDF 文件时使用 Responses | 保留输出 Token 参数选择；Responses 使用 `max_output_tokens` |
| Anthropic | Messages | `max_tokens`、Temperature、图片与 PDF |
| DeepSeek、vLLM、自定义 | 配置的 OpenAI 兼容接口；自定义可选 Anthropic 协议 | 保留 Base URL、模型 ID 和独立生成参数 |
| Ollama | 原生 `/api/chat` | 保留 `options.num_ctx`、`options.num_predict`、Temperature 和 `think`，转换 NDJSON 流供 pi 使用 |

上下文上限用于 pi 的压缩预算；不会作为所有供应商都接受的 HTTP 参数发送。只有 Ollama 的上下文设置还会下发到服务。未配置且未发现上下文上限时，代理按至少 32,768 Token 的本地预算计算，并为输出预留空间；这不代表服务端模型的真实能力。

Base URL 填 API 根地址，不包含具体请求路径。远程地址要求 HTTPS；HTTP 仅允许本机回环地址。请求不自动跟随重定向。Temperature 留空时不强行发送。

ChatGPT 订阅与 OpenAI API 配置独立，订阅无需 API Key。登录后优先读取账户模型目录，支持新增模型；目录暂不可用时显示 pi SDK 内置目录并明确提示，可点击「刷新模型」重试。SDK 当前包含 GPT-6.1 Sol、GPT-6 Astra、GPT-6 Luna 等模型，实际可用性取决于账号与客户端权限。刷新目录保留每个模型已有参数。

订阅模型在输入框下显示 **5 小时**、**7 天**剩余百分比，悬浮查看用量和重置时间。额度来自 `/wham/usage`，按服务实际返回的窗口时长匹配；未返回的窗口显示「未知」。当前可见会话每分钟、窗口重新获得焦点及请求结束时刷新，主进程合并并发读取并缓存 30 秒；退出账号清除缓存。读取失败显示中文原因，不推算或虚构额度。

订阅的令牌交换、自动续期、模型目录、额度和推理请求统一使用 Electron 网络通道，沿用系统代理且不发送浏览器 Cookie。浏览器能登录而应用无法交换令牌时，页面与应用都会显示对应的中文原因和 HTTP 状态，不展示授权码、令牌或上游原始正文。模型调用与会话仍由 pi SDK 管理。

## 会话与附件

界面会话保存在 `~/.pi-agenda/conversations.json`；pi 的完整 JSONL 会话保存在 `~/.pi-agenda/agent-sessions/`。聊天 ID 对应独立目录，保留工具调用、工具结果、压缩记录和快照关联。首次使用 pi 时导入已有聊天，后续只提交新输入；切换模型仍沿用该聊天的完整代理历史。

会话长期保留，只有用户删除聊天或所属项目时才删除其 pi 会话数据。重启应用后优先恢复 pi 的完整记录；取消后的用户消息与已完成结果也保留。失败或取消时保留草稿。

上下文压缩由 pi 负责，偏好设置中的压缩阈值映射到预留 Token 预算。压缩不删除本地原始记录，旧摘要逻辑不会与生产代理调用同时运行。

附件随消息保存。文本、图片、PDF、音频及其他文件在发送前转换为所选供应商支持的格式；供应商不支持的格式返回中文错误。pi 会话中保留原始附件，内部关联标识不会发送给模型服务。图片、PDF 或音频是否可理解仍取决于所选模型。

## 工具与快照

文件工具检查项目路径和联接点，拒绝越出项目或直接操作 `.git` 等元数据。命令工具以项目为工作目录运行，**这不构成操作系统沙箱**；命令仍具有当前用户的系统权限。没有关联项目的聊天不启用工具。

首次执行编辑、写入或命令前创建影子快照；任务结束、失败或取消后尝试保存修改后快照。只有修改前快照成功，工具才开始执行。影子 Git 不修改项目自身的仓库、索引或提交。

回滚先保存保护快照，检查本轮文件是否有后续修改，再仅恢复本轮涉及的文件，支持新增、删除和二进制内容。检测到后续修改时停止回滚。快照沿用既有排除规则：依赖、构建产物、`.env` 与凭证目录不进入快照；这些内容及项目外命令副作用无法通过快照撤销。项目包含未排除的符号链接时，快照会拒绝创建，修改工具因此停止。

## 密钥与请求边界

供应商配置仍保存在 `app.getPath('userData')/model-settings.json`。API Key 使用 Electron `safeStorage` 加密；Renderer 只能看到是否配置密钥。ChatGPT 订阅凭证使用相同的系统安全存储加密，保存于 `app.getPath('userData')/chatgpt-auth.enc`，主进程负责读取和自动续期，退出账号删除凭证。安全存储不可用时拒绝保存，不降级为明文。其他 pi 凭证使用内存存储，不额外写明文 `auth.json` 或 `models.json`。不自动发现或加载机器上的 pi 扩展、技能、模板和其他供应商凭证。

超时覆盖整个任务，包括上下文压缩、模型调用和工具执行；一次只运行一个任务。模型输出超过 2 MiB 时中止本次响应。已知密钥回显在流式文本和代理记录写入前脱敏；上游错误正文不会直接展示。

新输入及首次迁移历史沿用现有消息和附件大小验证；已经保存的完整历史由 pi 管理，不因界面每轮重复发送全部消息而触发消息数量上限。

## 验证范围

自动测试使用真实 pi SDK 与本地模拟接口，覆盖流式调用、模型参数、会话重启恢复、工具循环、取消、pi 上下文压缩、附件、Ollama 原生参数、Anthropic 缓存 Token、密钥脱敏、二进制回滚及手动修改保护。界面测试覆盖流式显示、事件隔离和消息恢复。真实云账户及各部署的工具调用兼容性仍需使用相应模型验收。
