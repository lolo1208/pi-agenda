# Pi Agenda · 行动派 产品与技术规格

更新日期：2026-10-09。本文记录目标范围，实现状态以[开发路线](development-roadmap.md)和[验收记录](acceptance-testing.md)为准。

## 项目定位

面向在本地项目中执行 AI 编程任务的开发者，提供 macOS / Windows 桌面工作台。用户提出代码需求、查看工具执行过程、逐轮检查差异，并能同时恢复文件和对话上下文。目标是安全、可控、可逆的代码自动化。

## 目标工作流

1. 选择项目，配置模型、Endpoint 和凭证。
2. 提交指令；若进入计划模式，先完成下述逐轮澄清和最终确认，再进入执行。执行开始时捕获 base 快照，记录运行中的 Turn。
3. 有界 Agent 循环处理模型输出、工具调用与工具结果，支持取消和失败记录。
4. 工具停止写入后捕获 end 快照，关联轮次并展示改动。
5. 用户查看 Diff 或选择历史轮次恢复；确认影响后同步切换文件和对话。
6. 新指令基于恢复后的活动上下文与文件继续执行。

## 界面要求

左侧项目与会话历史，中间流式对话与工具事件，右侧代码/Diff。每轮嵌入 ChangedFilesList，显示状态及增删行数，二进制明确标识。设置管理模型、Endpoint、凭证和连接测试。回滚前展示影响范围与未捕获改动，区分硬恢复和分支恢复。

会话项悬停或键盘聚焦时，在删除按钮之前显示编辑按钮。编辑弹窗可修改会话名称和会话提示词；保存后随会话持久化，手动名称不会被后续消息自动覆盖。会话名称不能为空，最长 200 个字符；会话提示词最长 32000 个字符。提示词从下一次发送生效，冲突时按「会话 > 项目 > 全局」优先，无冲突的指令共同生效；清空会话提示词后继续使用项目和全局提示词。

## Skill 自定义与导入

支持用户创建和编辑 Skill，设置名称、说明与指令内容；支持从本地 `SKILL.md` 或包含它的目录导入，保留包内引用资源。导入前展示来源、内容和校验结果，名称/标识冲突时由用户选择替换或另存，不静默覆盖。管理页提供查看、编辑、启用/停用和删除，任务可显式选择 Skill，记录实际使用的版本。

内置 Skill 与用户 Skill 分开管理。计划模式作为随应用分发的内置 Skill，用户导入的同名 Skill 不得覆盖它或解除最终确认限制。导入和编辑仅保存定义，不自动执行其中的指令或脚本。首版不包含在线 Skill 市场；后续可扩展导入来源。

## 计划模式：逐轮选择，确认后执行

1. 用户进入计划模式，内置 Skill 引导梳理目标、范围、使用场景、约束、交付物和验收标准。
2. 每个需要用户回应的交互轮次都弹出选项面板，说明本轮问题并提供明确选项；**最后一项固定为「自定义输入」**，允许输入选项之外的补充或修正。不能仅显示普通文本问题替代选项交互。
3. 等待用户实际提交后再进入下一轮；不将默认选中、关闭弹窗、超时或空输入视为回答。后续问题依据已有答案生成，不重复询问已明确的信息。
4. 持续交互直到需求明确、关键冲突和未决项解决。用户可以更正之前的选择；需要补充时继续弹出下一轮选项，不提前执行任务。
5. 交互完成后，完整展示需求汇总：目标、背景、范围内/范围外事项、功能与交互、技术和其他约束、交付物、验收标准、用户选择及明确接受的假设。附拟执行步骤和影响范围，不以简短摘要或执行步骤替代完整需求。
6. 汇总后的最终面板提供「确认并执行」「返回修改」「取消」，最后一项仍为「自定义输入」。只有用户明确点击「确认并执行」才进入执行；自定义补充或返回修改会生成新版需求，必须再次完整展示并确认。
7. 确认前只进行需求对话、计划记录及必要的只读上下文查看，不写入项目、不应用补丁、不执行 Shell 或其他产生外部副作用的任务操作。确认后基于已确认版本执行；需求范围发生变化时暂停相关执行，重新汇总并确认。

计划对话、选项答案、需求版本和确认状态需要持久化。关闭或重启后可继续澄清，但不能自动视为确认或自动恢复执行。最终确认不替代执行阶段对具体危险操作的独立审批。

## 约束与范围

- 不修改用户原 `.git` 的索引、历史和配置。
- Renderer 不直接访问文件、进程、密钥或任意 IPC；主进程验证来源和输入。
- 文件工具覆盖路径越界、符号链接和平台差异；风险命令需确认，不能将黑名单当作沙箱。
- 文件系统与 SQLite 不共享原子事务；恢复需日志、恢复点和崩溃补偿。
- 文件快照不等同于磁盘级完整备份；明确排除项及元数据范围。
- 目标平台为 macOS Intel/Apple Silicon、Windows 10/11；最低系统版本须与实际 Electron 版本核对并验收。
- 云同步、多人协作、插件市场、远程项目和自动更新服务暂不纳入首版四阶段交付。
